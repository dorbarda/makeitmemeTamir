<objective>
Apply a make-it-meme-style visual overhaul to the existing Hebrew-RTL, mobile-first client (bold
chunky Heebo weights, a gradient sunburst backdrop, gradient/drop-shadow "card" buttons) using only
original CSS — no makeitmeme.com code, art, fonts, or branding — while reusing the user's own
bachelor-party hero photo (`client/public/tamir-photos/main-photo.jpeg`) as a background motif on
the landing, lobby, and end-game screens.

Purpose: `client/public/tamir-photos/` is not a generic assets folder — `server/src/rooms/photos.ts`
(`loadPhotoFilenames()`) enumerates every `.jpg`/`.jpeg`/`.png` file in that exact directory at
server start via `readdirSync` and treats the whole list as the pool `assignPhotos()` /
`assignPhotosFromEligiblePools()` randomly hand out to players as their gameplay photo each round.
Leaving `main-photo.jpeg` there risks it being dealt to a player as a caption photo, which is wrong —
it must move out of that directory before any styling work reuses it as a hero image. Confirmed via
`grep -rl main-photo` across `client/`, `server/`, `shared/` that no code currently references the
filename by name (the manifest is filename-agnostic, so removing the file from the watched directory
is sufficient by itself), so the move needs no companion code change in `photos.ts`.

Output: `main-photo.jpeg` lives at `client/public/branding/hero-groom.jpeg` and is excluded from the
round-photo pool; `client/src/index.css` carries a new party-gradient palette, a chunky
gradient/drop-shadow button and card treatment applied across every existing screen, and a `.hero-bg`
utility wired onto the Home (landing), Lobby, and Round's `GAME_END` (end-game) `<main>` elements;
`dir="rtl"`/Hebrew text, word-spacing-only convention, and the full existing test/build suite are
all unaffected.
</objective>
